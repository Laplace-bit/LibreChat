# 当前工作队列（桌面体验）

本文件是 `agent-platform` 桌面体验的**动态工作队列**，随进度更新。静态交互规则见 `@native-desktop-ux.md`，壳工程与本地运行见 `@electron-client.md`。桌面 UX 工作使用 `native-feel-cross-platform-desktop` 技能。

## 首批顺序（按用户影响排序，尚未开始）

1. **登录恢复** —— 重启/唤醒后恢复会话，避免重复登录。
2. **搜索、技能和分享的错误状态** —— 补齐加载 / 空 / 失败 / 可取消 / 重试的状态呈现。
3. **请求取消和窗口状态保存** —— SSE 取消、窗口位置/大小/状态恢复。
4. **减少动态效果与平台适配** —— reduced-motion、深浅色、高对比、多显示器/Retina/中文输入法/无障碍。

> 顺序是基线，依据验证结果调整；不靠增加延迟、禁用交互或隐藏问题来规避体验问题。

## 验收基准

- 即时反馈目标 ≤50ms，60/120Hz 流畅，低资源占用；交互连续、焦点稳定、动画自然且可中断。
- 异步操作明确呈现加载/执行/成功/失败/可取消；处理空态、边界、大数据、重复操作、网络异常。
- 防数据丢失：适用处支持撤销、自动保存、错误恢复、工作状态恢复。
- 一个渲染器服务 macOS + Windows；系统字体、原生窗口/菜单、正确修饰键（macOS Command / Windows Control）。
- 键盘导航、屏幕阅读器命名、reduced-motion、高对比保持可用。
- 测量目标而非宣称达标；遇到体验问题解决根因。
