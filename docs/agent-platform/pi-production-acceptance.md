## 基线约束

- 对照基线是 `feature/pi-agent-runtime` 的 `30f389c4e2af5eaa7c7ba2a7353c4f49b3370132`。之后的提交不自动继承本清单的状态。
- 本分支没有进程内 Legacy Agent 回退。Pi 失败、沙箱不可用、身份无法验证或不支持的能力必须失败关闭，不能改派到上一版 Agent 引擎。

- G11-09 至 G11-20 规定桌面与 Web 要观察到的结果。G11-21 至 G11-24 规定这些结果要在 macOS 与 Windows 实机上各做一遍。两组都未验收，不能互相代替。
